Heyy! Mission Milkyway is a non profit organization founded to spread awareness and insights into how we can stop or at the very least reduce light pollution. Though founded by motivation to reduce light pollution, it's not limited to only that! We care about everything that supposed to be protected and nurtured like coral reefs and oceans.

The website is live here: https://missionmilkyway.github.io/MissionMilkyway/
